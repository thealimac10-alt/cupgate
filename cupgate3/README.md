# Cupgate (BG3 x Cuphead) — early scaffold
Brings Cuphead's boss-fight flow to Baldur's Gate 3: a "WALLOP!" banner when combat starts and a "KNOCKOUT!" rank (S/A/B/C by rounds) when it ends.
Requires: Baldur's Gate 3 + BG3 Script Extender (Melty installs it). Single player. Cuphead is inspiration only, not required.
Status: UNTESTED. Hooks in design/systems.json are all unverified. Not yet packaged as a .pak, so not publishable on Melty yet.
Layout: design/*.json (sheets, source of truth), Mods/CupgateBossRush (mod source).
